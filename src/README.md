# 禅心修行 - 冥想应用

一个基于 React + 云开发的冥想应用，帮助用户进行日常冥想修行。

## 设计理念

### 美学方向
- **风格**: 有机/自然风格
- **色彩调色板**:
  - 主色: #2D5A3D (深绿色 - 代表自然与平静)
  - 辅助色: #8FB996 (浅绿色 - 代表生机)
  - 强调色: #D4A574 (暖棕色 - 代表温暖)
  - 背景色: #F5F0E8 (米白色 - 代表纯净)
  - 文字色: #3D3D3D (深灰色 - 代表稳重)

### 字体排版
- 标题字体: Playfair Display (优雅的衬线字体)
- 正文字体: Noto Serif SC (中文衬线字体)

### 布局策略
- 非对称布局，打破传统居中设计
- 使用圆形装饰元素营造流动感
- 渐变和模糊效果创造深度

## 功能特性

### 用户认证
- 用户注册
- 用户登录
- 用户登出

### 冥想功能
- 多种冥想课程（晨间冥想、深度放松、正念呼吸、睡前冥想）
- 冥想计时器
- 播放/暂停/重置控制
- 完成冥想后自动记录

### 数据统计
- 总冥想分钟数
- 连续修行天数
- 完成次数统计

## 项目结构

```
├── pages/                    # 页面组件
│   ├── welcome.jsx          # 欢迎页
│   ├── login.jsx            # 登录页
│   ├── register.jsx         # 注册页
│   └── home.jsx             # 主页（冥想界面）
├── .functions/              # 云函数
│   ├── login/               # 登录云函数
│   ├── register/            # 注册云函数
│   └── logout/              # 登出云函数
├── .datasources/            # 数据源
│   ├── users/               # 用户数据模型
│   └── meditation_stats/    # 冥想统计数据模型
├── components/              # 可复用组件
│   └── ui/                  # shadcn/ui 组件库
├── index.css                # 全局样式
└── tailwind.config.ts       # Tailwind 配置
```

## 数据模型

### users (用户表)
- `username`: 用户名
- `email`: 邮箱（唯一）
- `password`: 密码
- `avatarUrl`: 头像URL
- `createdAt`: 创建时间
- `updatedAt`: 更新时间

### meditation_stats (冥想统计表)
- `userId`: 用户ID
- `totalMinutes`: 总冥想分钟数
- `streakDays`: 连续天数
- `sessionsCount`: 完成次数
- `lastSessionDate`: 最后一次冥想日期
- `createdAt`: 创建时间
- `updatedAt`: 更新时间

## 云函数

### login
验证用户登录信息

**参数**:
- `email`: 邮箱
- `password`: 密码

**返回**:
- `success`: 是否成功
- `data`: 用户信息
- `message`: 提示信息

### register
创建新用户账户

**参数**:
- `username`: 用户名
- `email`: 邮箱
- `password`: 密码

**返回**:
- `success`: 是否成功
- `data`: 用户信息
- `message`: 提示信息

### logout
用户登出

**返回**:
- `success`: 是否成功
- `message`: 提示信息

## 使用说明

### 1. 首次访问
用户首次访问会看到欢迎页面，可以选择登录或注册。

### 2. 注册账户
填写用户名、邮箱和密码完成注册。

### 3. 登录
使用注册的邮箱和密码登录。

### 4. 开始冥想
- 选择一个冥想课程
- 点击播放按钮开始
- 完成后点击心形按钮记录
- 查看统计数据更新

### 5. 退出
点击右上角的退出按钮返回欢迎页。

## 技术栈

- **前端框架**: React
- **UI 组件**: shadcn/ui
- **样式**: Tailwind CSS
- **图标**: lucide-react
- **表单**: react-hook-form
- **后端**: 腾讯云开发
- **数据库**: 云数据库（NoSQL）
- **云函数**: 云函数

## 开发说明

### 页面路由
- `welcome`: 欢迎页（默认页）
- `login`: 登录页
- `register`: 注册页
- `home`: 主页

### 状态管理
使用 React Hooks 进行状态管理，包括：
- `useState`: 组件状态
- `useEffect`: 副作用处理
- `useForm`: 表单状态

### 错误处理
使用 Toast 组件显示错误和成功信息，确保用户获得及时反馈。

## 注意事项

1. **密码安全**: 当前实现中密码未加密，生产环境应使用加密存储
2. **数据验证**: 前端和后端都进行了数据验证
3. **用户体验**: 所有操作都有加载状态和错误提示
4. **响应式设计**: 支持移动端和桌面端
